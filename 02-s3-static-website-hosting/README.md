# 🌐 Static Website Hosting on Amazon S3

## 📖 Project Description
This project demonstrates how to host a static website using Amazon S3. The website is publicly accessible through the Amazon S3 Website Endpoint by configuring static website hosting, bucket permissions, and routing rules.

---

## 🎯 Objectives
- Create an Amazon S3 bucket
- Upload static website files
- Enable Static Website Hosting
- Configure Bucket Policy for public access
- Configure Redirection Rules
- Access the website through the S3 Website Endpoint

---

## 🛠️ AWS Services Used
- Amazon S3
- AWS Management Console
- IAM

---

## ⚙️ Implementation Steps
1. Created an Amazon S3 bucket.
2. Uploaded the static website files (`index.html`, `style.css`, `script.js`).
3. Enabled Static Website Hosting.
4. Set `index.html` as the index document.
5. Applied a Bucket Policy to allow public read access.
6. Configured Redirection Rules.
7. Accessed and verified the website using the S3 Website Endpoint.

---

## ✨ Features
- Static website hosting
- Public website access
- Bucket Policy configuration
- Website endpoint access
- Routing and redirection support
