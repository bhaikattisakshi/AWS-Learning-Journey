# EC2 Instance Creation and Access Using SSH and AWS CLI

## Project Overview

In this project, I created an Amazon EC2 instance and accessed it securely using SSH. I also installed and verified AWS CLI on the EC2 instance.

## Technologies Used

* Amazon EC2
* SSH
* AWS CLI
* Amazon Linux
* Windows Command Prompt

## Key Learning

* Created and launched an EC2 instance
* Connected to the instance using SSH
* Verified AWS CLI installation
* Executed basic AWS CLI commands
