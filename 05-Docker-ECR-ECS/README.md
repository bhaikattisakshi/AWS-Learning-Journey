# Dockerized Node.js Application Deployment using Amazon ECR and ECS

## 📌 Project Overview

This mini project demonstrates how to containerize a Node.js application using Docker and deploy it on AWS using Amazon ECR and Amazon ECS.

## 🏗️ Architecture

GitHub → Docker → Amazon ECR → Amazon ECS → Running Container → CloudWatch

Additional AWS services used:

* Amazon EC2
* IAM
* Amazon ECR
* Amazon ECS
* Amazon CloudWatch

## 🚀 Steps Performed

1. Created and tested the Node.js application.
2. Created a Dockerfile for the application.
3. Built the Docker image.
4. Tested the application using Docker.
5. Created an Amazon ECR repository.
6. Tagged and pushed the Docker image to ECR.
7. Created an ECS cluster.
8. Created an ECS task definition.
9. Configured IAM permissions.
10. Deployed the container using Amazon ECS.
11. Configured port 8000 for the application.
12. Verified the application through the public endpoint.
13. Used CloudWatch for container logs and monitoring.
